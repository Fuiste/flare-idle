# changelog

## 0.1.0-preview.1

- initial windows x64 preview for supported native flare packages.
- manual start, resident model, inference-first mining admission, and configurable idle grace.
- setup ui for model/runtime/trust files, selected nvidia gpu, optional power cap, and krig pool/user/password settings.
- restores the pre-session power cap and leaves clocks, voltage, and fans alone.
- protected local settings, loopback gateway, process ownership, and guardian recovery.

validation covers cpu fixtures and local read-only discovery. this preview does not claim broad hardware, long-context, overnight thermal, or mining-profitability qualification.
